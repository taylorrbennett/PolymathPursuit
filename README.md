# Polymath Pursuit 🎓🧠

*A multiplayer trivia game where each player chooses their own expertise.*

---

# Overview

**Polymath Pursuit** is a multiplayer trivia game built in Java that allows users to choose their preferred category. This is a contrast between traditional trivia games that do not allow users to choose their preferred category.

This project was developed as a dissertation project that focuses on Java application development, multiplayer game design, and user experience.

---

# Features

## ☕ Built with Java

Was developed with object-oriented programming principles.

## ⏱️ Timed Questions

Players will have a set time limit.

## ❓ Question System

Questions will come from the categories the user chooses.

## 🏆 Scoring System

Live score tracking and points awarded for correctly answering questions.

## 🎮 Multiplayer Gameplay

Multiple users will be able to play in real-time.

## 🔄 Replay

An abundance of questions and topics so each game is different.
